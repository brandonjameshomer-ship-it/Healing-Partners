Generate a JSON schema for a two-stage headstone design system:

STAGE 1 - MEMORIAL STRUCTURE:
Memorial types: Upright Monuments, Family Monuments, Flat Markers, Sculpted Monuments, Ledgers, Memorial Benches, Monubenches, Vases, Custom Shapes.
For each: id, name, description, dimensions (height/width/depth ranges), base options, price tier (Lower/Moderate/Higher/Premium), production time (3-12 months), available materials.

STAGE 2 - SURFACE DESIGN:
- Emblems: religious, professional, hobby, custom graphics
- Layout: positioning zones (top/center/bottom/full-spread)
- Borders: style options with width/depth
- Typography: font families, sizing (for stone legibility)
- Decorative Elements:
  * Carvings: depth levels, styles
  * Inlay: stone/metal options
  * Beveled Edges: depth/style options
  * Photos: placement zones, quality specs
- Text Fields: name, dates, epitaph areas (with character limits)

OUTPUT: JSON schema with:
1. Memorial structure as selection (mutually exclusive options)
2. Surface design as composable layers
3. Validation rules (text limits, dimension constraints)
4. Design preview metadata
5. Production spec generation capability

Ensure Stage 1 selection constrains relevant Stage 2 options (e.g., flat markers can't have tall carvings).
