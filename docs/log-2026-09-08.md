## 2. Cross-device test harness — `playwright-mobile-demo/`

Playwright with 14 projects: desktop Chrome, Firefox and Safari-engine; iPhone SE,
Galaxy S9+, Galaxy S24, iPhone 15, Pixel 8, iPhone 16 Pro Max; iPad gen 7 and
iPad Pro 11 landscape; plus dark-mode and reduced-motion variants. Two spec files
cover the hub page (overflow, panel switching, contrast, chips, turntable by
slider/keyboard/drag, plot grid, voice transcript, deep links) and every Remember
Them page (clean load, iOS input zoom, tap targets, save/reload, trial gate,
intake, life interview). A dependency-free Node static server (`tests/serve.cjs`)
replaces `python3 -m http.server`, because macOS's `python3` is an Xcode shim that
stops working while the Xcode license is unaccepted. `sim/run.sh` drives the iOS
Simulator once Xcode's runtime is installed.

Result: **420 / 420 passing.** It found one real bug — the designer's size
`<select>` at 13 px, which makes iOS zoom the page on focus — and several
sub-44 px touch targets. Both fixed with CSS under `@media (pointer:coarse)`.
